# Практическая работа № 2 — вариант 2

Дата: 12 октября 2026 года. Тема: каталог книг.
Удалённая площадка по указанию пользователя: GitHub.
Репозиторий: https://github.com/Comper123/library

## 1. Инициализация

В папке library выполнен `git init -b main`. На уровне репозитория настроены
`user.name=Ilia` и `user.email=ibarishnikov07@mail.ru`.
Первые три тематических коммита: правила исключения, Python-каталог,
инструкция запуска и пример JSON. Рабочий books.json не отслеживается.

## 2. Атомарные изменения

Добавление книги, поиск автора и экспорт JSON реализованы отдельными коммитами.
Перед реализацией подготовлены тесты с воспроизводимым падением, затем
добавлен код и выполнены проверки. Документация вынесена в отдельный коммит.
Перед фиксацией выполнены `git diff` и `git diff --staged`.
Сообщение `docs: describe catalog comands` исправлено через
`git commit --amend -m "docs: describe catalog commands"`.

## 3. Ветка функции

В feature/isbn-search сделаны два коммита: функция нормализации и поиска,
затем CLI-команда и документация. Проверки пройдены. Ветка слита через
`git merge --no-ff feature/isbn-search` и удалена командой `git branch -d`.

## 4. Конфликт

Обе ветки созданы от одной точки с MAX_BOOKS = 50.
В change/a установлено 100, в change/b — 500. После слияния change/a
слияние change/b вызвало конфликт одной строки books.py.
Маркеры удалены, итог — MAX_BOOKS = 500. Ограничение описано в README.
Тест проверяет отказ при 500 книгах и успешное добавление при 499.
Перед завершением merge выполнены тесты.

## 5. Выпуск и восстановление

Метка выпуска: аннотированная v0.5.0.
В recovery-demo незакоммиченная строка MAX_BOOKS = 500 временно заменена на 1.
`git status --short` показал изменение, `git diff` — замену.
Команда `git restore books.py` восстановила файл из индекса, соответствующего HEAD.
После восстановления diff пуст, лимит снова 500, тесты проходят.
Команда выбрана для отмены незакоммиченного изменения одного файла;
история коммитов не меняется. Ветка main снова активна.

## Проверка и доказательства

5 тестов unittest проходят. Подробные команды, staged diff, конфликт,
граф истории и состояние до/после восстановления сохранены в COMMANDS.md.

Команды отправки на GitHub:

```powershell
git remote add origin https://github.com/Comper123/library.git
git push -u origin main change/a change/b recovery-demo
git push origin v0.5.0
git log --graph --oneline --decorate --all
git show v0.5.0
```
